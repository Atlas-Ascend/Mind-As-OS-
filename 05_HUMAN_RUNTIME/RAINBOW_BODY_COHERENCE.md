# Rainbow Body — Coherence Controller

Canonical implementation models Rainbow Body as balanced integration across three soft channels:
- Presence
- Pattern
- Expression

The control objective is proportion/coherence, not maximum accumulation. A highly lopsided state must not qualify merely because one channel is high.

Rainbow Body is system-level telemetry/emergent state, not an agent, superweapon, metaphysical proof or permission-escalation mechanism.

It can inform runtime reflection and mode balancing; it cannot authorize external writes.
