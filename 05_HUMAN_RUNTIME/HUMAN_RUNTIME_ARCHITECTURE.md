# Human Runtime Architecture

Runtime state should minimally distinguish:
- current signals and source
- attention/salience
- affect/state telemetry
- active memories/context
- identity-state hypothesis
- relational/environment model
- SEVEN orientation
- ALI-9 posture candidate
- Tri-Mode authority mode
- ODDEC transaction phase
- stewardship/governance checks
- action status
- feedback/provenance
- coherence telemetry

All inferred states carry uncertainty and source. No runtime field can silently become software permission.
