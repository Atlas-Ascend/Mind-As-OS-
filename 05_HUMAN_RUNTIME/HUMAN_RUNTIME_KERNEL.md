# Human Runtime Kernel

The kernel is the transition/control layer beneath named cognitive organs.

Responsibilities:
- event admission and source labeling
- state transition rules
- context switching
- interruption handling
- priority/salience scheduling
- working-context assembly
- fault isolation between interpretation and identity
- recovery/checkpoint semantics
- provenance for model updates
- authority separation

Example invariant: `AURA observes a state` does not imply `identity permanently equals that state`; `Cipher finds a symbolic mapping` does not imply `mapping is objective fact`; `ALI-9 suggests a posture` does not grant write authority.
