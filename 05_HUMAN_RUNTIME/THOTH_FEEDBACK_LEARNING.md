# THOTH, Feedback and Learning

THOTH is continuity/provenance memory: what happened, what was observed, what was decided, what changed and what evidence exists.

Cognitive Genome learning is a slower model-update layer: what recurring pattern is hypothesized to be changing?

`EVENT != PATTERN != IDENTITY`.

Pattern promotion should require multiple observations where appropriate, confidence, contradiction handling, provenance, version history and a correction/rollback path.
