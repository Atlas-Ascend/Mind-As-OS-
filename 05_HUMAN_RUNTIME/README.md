# 05 — Human Runtime

This layer describes the live, moment-to-moment operating system: current signal, attention, state, active memory, identity context, relationship context, mode, deliberation, governance, action, feedback and recovery.

Runtime is dynamic state, not a permanent description of a person.

Core loop:
`SIGNAL -> PERCEPTION -> AURA/SAGE -> NAVI/NHCM -> SEVEN/ALI-9 -> CARTOGRAPHY/ARCHITECTURE -> TRI-MODE + ODDEC -> STEWARDSHIP -> AUTHORIZED ACTION -> THOTH/PROOF -> FEEDBACK`.
