# Stewardship + Medusa Runtime Boundary

Stewardship evaluates care, responsibility, consent, boundaries, reversibility, consequences and non-domination.

Medusa enforces security/public-private/exposure boundaries at the machine/estate interface.

Human meaning/governance and machine authorization remain separate:
`interpretation -> stewardship -> proposed intent -> JANUS/ODIN policy -> capability check -> execution`.

Passing a stewardship check is not proof that an interpretation is true, and it is not machine permission.
