# Cognitive-to-Estate Crosswalk

The human cognitive architecture and the software organism are coupled, but they are not the same layer.

| Human cognitive organ | Function | Software/estate handoff |
|---|---|---|
| Perception / Attention | acquire and select signal | signal/context envelope |
| AURA | internal-state telemetry | Atlas Mind context, never direct write authority |
| SAGE | relational/environmental assessment | context/risk/relationship annotations |
| Observer | evidence gathering | read-only capability set |
| Cartographer | relationship/topology mapping | Universal Atlas / CaseGraph / CrownGrid map surfaces |
| Architect | simulation and plan authoring | candidate plan / Packet OS draft |
| Creator | requested transformation | JANUS/ODIN authorization boundary |
| ODDEC | decision/action lifecycle | packet lifecycle and THOTH receipts |
| Stewardship | values/consequence/boundary governance | JANUS policy + Medusa boundary checks |
| SEVEN | state orientation | advisory state metadata |
| ALI-9 | executive posture synthesis | advisory strategy metadata |
| THOTH | memory / lineage | durable event/proof memory |
| NHCM / CSA | ontology and classification | typed schemas / graph taxonomy |
| Cipher / Lexicons | semantic translation | structured tags/semantic representations |
| Cognitive Genome | learned-pattern model | versioned, provenance-bearing model update |
| Rainbow Council | polycentric advisory synthesis | advisory council outputs |
| Rainbow Body | integrated coherence | coherence telemetry only; no permission escalation |
| Behavior / Action | embodied outcome | Workforce Spine / MetaForge / EDEN / external tools |
| Verification | reality check | SECA / DevOS |
| Proof | evidence of outcome | ProofGrid |

## Hard boundary

No psychological, symbolic, archetypal, spiritual, emotional or coherence state can implicitly grant software capabilities. Write permission must still come from the explicit capability + executive authorization model.
