# Canon Genealogy

This directory is the provenance control plane for Mind As OS.

It does not create cognitive systems. It records where definitions came from, which roles are current, which roles are historical, what was superseded, what conflicts remain, and what evidence is still missing.

## Truth law inherited from GA-HEP-FORENSIC-MASTER-EXTRACTION-001

- MENTION != IMPLEMENTATION
- DESIGN != RUNTIME
- HISTORICAL_PROOF != CURRENT_PROOF
- LEGACY_DONOR != CANONICAL_AUTHORITY
- ALIAS != DISTINCT_SYSTEM

## Status vocabulary

- `CANONICAL_CURRENT`
- `CANONICAL_HISTORICAL`
- `SUPERSEDED_COMPATIBLE`
- `MULTI_ROLE_SPLIT`
- `CANON_CANDIDATE`
