# Observer → Cartographer → Architect → Creator

These are cognitive transformation roles, not four equivalent machine permission levels.

- **Observer / SEE:** acquire evidence; no mutation.
- **Cartographer / MAP:** construct topology, relations, dependencies and history; no mutation.
- **Architect / FRAME/DESIGN:** model counterfactuals and plans; preview only.
- **Creator / BUILD:** request or perform an authorized transformation after governance/capability checks.

Canonical Tri-Mode remains Observer / Architect / Creator. Cartographer is modeled as an intermediate mapping function unless future provenance proves a separate authority-mode contract.
