# SEVEN + ALI-9

## SEVEN — recursive state orientation
1. STILLPOINT — regulation/safety/baseline
2. CLARITY — perception/orientation
3. COHERENCE — integration/alignment
4. INTENTION — direction/choice
5. FLOW — execution/creation
6. TRANSCENDENCE — expanded perspective/connection
7. MASTERY — skillful governance across all states

Mastery is not permanent residence at state seven.

## ALI-9 — mature-capacity synthesis
ALI-9 receives state and relational information and proposes an operating posture/archetypal capacity. It remains advisory; it does not override agency, Tri-Mode authority, JANUS/ODIN or capability policy.

SEVEN answers **what operating state?** ALI-9 answers **what posture/capacity may fit?**
