# Human Factors + Cognitive Systems Engineering

## Human Factors
Design around actual human capabilities/limitations: visibility, workload, working-memory burden, interruption cost, accessibility, fatigue, recoverability, warning clarity and override usability.

## Cognitive Systems Engineering
Model the work domain and how people build situation models under uncertainty:
`WORK DOMAIN -> INFORMATION -> SITUATION MODEL -> DECISION -> ACTION -> SYSTEM RESPONSE -> UPDATED MODEL`.

For Ghost Atlas, this maps naturally to Reality Graph -> Observer/Cartographer -> AURA/SAGE/NAVI -> Architect/ODDEC -> authorized action -> THOTH/proof -> updated map.
