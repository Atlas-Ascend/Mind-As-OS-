# Whole Human System

```text
BODY / NERVOUS SYSTEM
  <-> PERCEPTION / ATTENTION
  <-> COGNITION / MEMORY
  <-> AFFECT / REGULATION
  <-> IDENTITY / SELF-MODEL
  <-> BEHAVIOR / AGENCY
  <-> RELATIONSHIPS
  <-> ENVIRONMENT / INSTITUTIONS
  <-> TECHNOLOGY
  <-> MEANING / VALUES
```

No single plane is allowed to explain the whole person. A human-systems claim should record level, context, observation source, uncertainty and competing explanations.
