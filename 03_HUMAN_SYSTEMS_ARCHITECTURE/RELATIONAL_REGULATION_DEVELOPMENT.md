# Relational, Regulation and Development Architecture

## Relational
Maintain distinct self, other and relationship models. SAGE contributes real-time relational telemetry; it does not collapse felt state into claims about another person.

## Regulation / recovery / reintegration
Model normal, loaded, degraded, stabilization, recovery, reintegration and updated-baseline states. Recovery is part of the architecture, not an exception.

## Development
Distinguish fast runtime changes from slow pattern/developmental changes. Cognitive Genome hypotheses require repeated evidence, confidence, contradiction support, version history and correction pathways.
