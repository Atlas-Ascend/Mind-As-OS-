# 00 — Canonical Charter

## Identity
Mind As OS is the governed cognitive operating-system model for the Ghost Atlas estate.

It defines how signals become context, context becomes cognition, cognition becomes bounded work, work becomes verified evidence, and verified evidence becomes updated state.

## Non-replacement rule
Mind As OS does not replace existing organs. It provides operating semantics across them.

- Atlas Mind: conversational/reasoning cognition
- EDEN: runtime body and local capability host
- Thoth: memory cortex and provenance
- JANUS / ODIN: executive control and routing
- Packet OS: atomic work substrate
- Workforce Spine: task bloodstream
- MetaForge: build factory
- SECA / DevOS: audit, inspection, finish truth and software support
- Medusa: security and public/private review
- CrownGrid: estate I/O and capability router
- GARI: resident worker/continuity agent
- ProofGrid: evidence and proof receipts

## Prime invariants
1. Authority is explicit and bounded.
2. Memory mutation carries provenance.
3. Execution is capability-scoped.
4. Handoffs are addressable and inspectable.
5. Failure routes are explicit.
6. Verification is independent from generation when practical.
7. Success claims require evidence.
8. No subsystem may silently promote its own authority.
9. No proof-class substitution is allowed without declaration.
10. Human override remains available at governed boundaries.

## Canonical lifecycle
SIGNAL → CONTEXT → STATE → REASON → DECIDE → PACKETIZE → ROUTE → EXECUTE → VERIFY → PROVE → COMMIT STATE → REFLECT.

## Proof criterion
This charter is implemented when every runtime work item can be traced from source signal to resulting evidence and state transition.
